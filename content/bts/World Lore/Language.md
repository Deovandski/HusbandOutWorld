# Vraki Language

The common language, inherited from the Finaies.

The Buhraies brought English-speaking humans into the mix and used memory and mind manipulation to take away their language. But language is such an embedded part of the soul that some of it kept on: when humans took over, the basic idea of building an alphabet stuck around, and its letters naturally fell in the same order as in English.

So Vraki is mostly English with a skin, since English is the common language of business communication and the language Deo wrote everything in. Old Vraki is Old English, with some random stuff thrown in.

# Finaies Interface Language

A logographic language that evolved over time.

# Buhraies Interface Language

A logographic language that grew out of the Finaies interface language, because of the mix of blood and Soul Energy.

# Darfaries Interface Language

A logographic language created by the ancient species, because Darfaries can't use the ancient species' interfaces. It has two parts: Subject and Verb.
