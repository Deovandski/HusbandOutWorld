# Legacy: the originals

Everything in this folder was made by humans: the story, the lore, the notes and the spreadsheets by **Deovandski Skibinski Junior**, and the illustrations by **Mitsukiven** and **Feiourm**. It's kept here unchanged as the source of truth and the inspiration for everything else in this repo.

The [website](https://www.husbandoutworld.com) is built from these files. Its build script only reads them: it never edits them, and it doesn't add lore of its own. Where the website shortens, rewords or fixes a typo, that change lives outside this folder (in [`content/`](../content)) so you can always compare it against the original. If the website and this folder ever disagree, **this folder wins**.

## What's inside

| Folder | What it is | Where it came from |
|---|---|---|
| [Public](Public) | The reader-facing version: the 33 pages of the old #HusbandOutWorld blog, as they were published. Light on spoilers. | The Blogger export (Google Takeout, November 2026), converted from HTML to Markdown word for word. |
| [Behind The Scenes](Behind%20The%20Scenes) | Everything else: the full light novel manuscripts, the author's story notes for Arcs #2 to #5, the complete World Lore documentation, the spreadsheets and formulas, the fonts, and every illustration with its source files. **Full of spoilers.** | This repo's original files, moved here unchanged. |

## Notes on the blog copy (Public)

- Each page keeps its original address, publish date and last update in the header at the top of the file.
- The blog's own text is untouched. Only the page format changed (HTML to Markdown).
- Every image the blog showed was downloaded at full size. Where it's the same picture as a file in `Behind The Scenes` (225 of 273), the page links to that file instead of keeping a second copy. The matches were made automatically by comparing the pictures. The other 48 are kept in [Public/images](Public/images), numbered in the order they appear on the blog.
- Two pages that were already in the blog's trash ("The Evolution of Deo Through the Afterwords" and an empty "World Lore" draft) were left out, as was the old blog's personal profile data.
